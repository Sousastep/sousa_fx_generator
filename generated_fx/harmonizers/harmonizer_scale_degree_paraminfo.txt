================================================================================
harmonizer_scale_degree — Parameter Information
================================================================================

OVERVIEW
Two harmony voices that stay in the key. The tuba's pitch (in3) is read as a
scale degree in the chosen key and mode, each voice is placed its own number of
scale degrees above that note, and a pitch-synchronous overlap-add voice sings
it (DAFx-07 Paper 69 Sec. 3.3 for the scale-degree harmonization rule;
DAFx-11 Paper 52 Sec. 4.1-4.2 for the PSOLA voice). Play a C in C major with
degree 2 and degree2 4 and the voices sing E and G; move to D and they move to
F and A.

By default the intervals are just: each voice is tuned to the horn itself with a
5-limit ratio (3/2 fifth, 5/4 major third, 6/5 minor third, 9/8 second, ...), so
the harmony pitch-locks with the tuba and never beats against it. This is not
the same as a fixed C-major just table: because every interval is tuned to the
note actually being played, the third above D is a pure 6/5 (315.6 cents), where
a static C-major scale would put it at 32/27 (294.1 cents). A doubling wants the
pure interval; set tuning 0 for equal temperament.

INLETS & OUTLETS
- in1 / in2: Stereo Audio Input (Tuba)
- in3: Tuba f0 in Hz. 0 or out-of-range (outside 20..1200 Hz) holds the last
  valid value; it starts at a fixed 82 Hz (the tuba's low E), so the effect is
  usable before the tracker locks. in3 is never divided by and never treated as
  1 Hz.
- in4: One-Bar Phasor [0..1]. Frozen at 0 the drift oscillator free-runs.
- out1 / out2: Stereo Output (dry crossfaded with the harmony voices)

PARAMETERS (8)

1. key
   - Range: 0 to 11 semitones above C (Default: 0 = C)
   - Taper: Linear chromatic index (0 C, 1 C#, 2 D, ... 11 B).
   - Function: The key of the scale used to place both voices.

2. mode
   - Range: 0 to 4 (Default: 0)
   - Taper: Index. 0 major, 1 natural minor, 2 dorian, 3 mixolydian,
     4 harmonic minor.
   - Function: The scale type. The leading tone of harmonic minor gives the
     voices a raised seventh against the tonic.

3. degree
   - Range: 1 to 7 scale steps (Default: 2)
   - Taper: Integer scale steps above the played note.
   - Function: Voice 1's distance up the scale. 1 = the next scale tone (a
     second above), 2 = a diatonic third, 4 = a diatonic fifth, 7 = the octave.
     Notes played between scale tones are snapped to the nearest degree before
     the interval is chosen, so the voice never leaves the key.

4. degree2
   - Range: 0 to 7 scale steps (Default: 4)
   - Taper: Integer scale steps above the played note.
   - Function: Voice 2's distance up the scale, 0 switches it off. With degree 2
     and degree2 4 the effect sings a diatonic third and fifth together; set
     degree2 7 for an octave, or degree2 2 for a two-voice third. The same value
     as degree stacks both voices in unison (about 3 dB louder). Switching it
     off fades voice 2 out over 20 ms instead of cutting a grain.

5. mix
   - Range: 0 to 100 % (Default: 40)
   - Taper: Linear dry-to-harmony crossfade.
   - Function: Balance between the tuba and the harmony voices. The two voices
     are summed first, so the dry/wet balance does not change when degree2 is
     switched.

6. glide_ms
   - Range: 5 to 200 ms (Default: 40)
   - Taper: Exponential time constant.
   - Function: How fast both voices slide to their new intervals when the horn
     changes note. Short values track fast licks; long values smear a slow
     portamento between the two notes.

7. drift_cents
   - Range: 0 to 25 cents (Default: 0)
   - Taper: Linear.
   - Function: Deliberate one-bar-rate detune, applied with opposite signs to
     the two voices so they breathe apart. At 0 (default) the just intervals are
     exact and nothing beats; any non-zero value trades that purity for a
     humanised, slowly drifting double. The phase comes from in4 when the phasor
     moves, otherwise from an internal oscillator.

8. tuning
   - Range: 0 or 1 (Default: 1 = just)
   - Taper: Switch (values below 0.5 select equal temperament).
   - Function: 1 places each voice on the 5-limit ratio for its interval above
     the horn: 9/8 and 16/15 for seconds, 6/5 minor and 5/4 major thirds, 4/3
     and 3/2, 45/32 tritone, 8/5, 5/3, 9/5, 15/8, 2/1. 0 uses equal
     temperament, where a major third above the horn is 13.7 cents sharp of the
     pure ratio and a minor third is 15.6 cents flat.

PORT NOTES
- The played note is snapped to the nearest key degree only to choose the
  intervals; the shifts are then applied to the real incoming f0, so the
  player's intonation and vibrato come through in both voices.
- Voices share one grain engine and one analysis-mark clock; each voice costs a
  second grain stream, so degree2 = 0 is also the cheapest setting.
- Octave-up shifts keep only the even source harmonics, so a voice spread is
  quieter than the dry horn; balance with mix.
