ADClip9 — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/adclip9/

What it is: a "loudenator" clipper — the ClipOnly3 engine inside ADClip.
Peaks above the Noise threshold are softened by blending toward a randomized
level (noise-edged clipping, which keeps some "over" detail), and everything
is finally held under a slew-aware hard Ceiling (the faster the waveform is
moving, the lower the ceiling, which tames intersample peaks). The output is
one sample late.

Parameters:

- drive_db  (Boost / Match)  0 .. 30 dB, default 0
  Gain into the clipper. In "boost" and "cliponly" modes it is the original
  Boost control, in "match" mode the original Match control (only one of the
  two was ever active, so they share one slider). The original stops at
  18 dB; 18..30 dB is an extension for a quiet tuba input.

- noise_db  (Noise)  -18 .. 0 dBFS, default -0.82
  Where the noise-softened clipping starts. Lower = the transition into the
  noisy clip starts sooner, without moving the hard limit. Original knob C:
  level = 1 - (1-C)^2, so C 0.7 = -0.82 dBFS.

- ceiling_db  (Ceiling)  -18 .. 0 dBFS, default -0.56
  The hard clip limit (further lowered while the signal slews fast). Lower =
  harder, duller, quieter. Original knob D: level = 1 - (1-D)^2, so
  D 0.75 = -0.56 dBFS. Defaults of both thresholds match ClipOnly3.

- mode_sel  (Mode)  boost / match / cliponly, default boost
  boost    - drive, then clip: pure loudening.
  match    - drive, clip, then remove the same gain: level-matched, so you
             hear only what the clipping does.
  cliponly - outputs only what the clipper took away, polarity-inverted
             (clipped minus dry, divided by drive). Silent until clipping
             starts; useful to audition or to parallel-process the spikes.

Port notes: DSP is sample-identical to the original double-precision path
(differential test vs. the airwindows C++, max diff below -150 dB, from
float vs. double parameter storage). The random generator now runs on
native integer operations — bit-identical sequence, about 60% fewer
ns/sample on a translated test harness. The VST's output dither is not
included (it is commented out in the original's 64-bit path too). Above
88.2 kHz the clip averaging spreads over more samples, as in the original.
