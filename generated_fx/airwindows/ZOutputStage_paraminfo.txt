ZOutputStage — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/zoutputstage/

What it is: the output stage of the Emu e6400-inspired Z filters on its
own: input drive, a very low DC-blocking highpass, a 15.5 kHz biquad
lowpass, a hard clamp at +/-1 followed by a gentle fifth-order soft
clip (x - 0.1768 x^5), a second 15.5 kHz lowpass, then output trim. A
dark, slightly smeared saturator — the "family sound" of the Z filters
without any filter sweep.

Parameters:

- input_db  (Input)  -24 .. +80 dB, default 0
  Drive into the clipper. Original knob A: gain = (10A)^4, so A 0.1 = 0 dB
  (the default) and A 1 = +80 dB — enormous on purpose. The soft clip
  bends from about -6 dBFS and the hard clamp is at 0 dBFS, so a normal
  tuba level needs +10 to +20 dB to really distort.

- output_db  (Output)  -36 .. 0 dB, default 0
  Output trim after the clipper (the original knob B was linear 0..1).
  Set the final level here, not with Input.

Port notes: DSP matches the original double-precision path (differential
test vs. the airwindows C++, max diff below -150 dB). The random generator
for the denormal guard runs on native integer operations (bit-identical),
about 73% fewer ns/sample on a translated test harness. The fixed 15.5 kHz
filters need a sample rate of 32 kHz or more.
