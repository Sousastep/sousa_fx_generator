VariMu — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/varimu-vst/

What it is: a more organic relative of Pressure. Two interleaved
mu-style gain cells per side trigger on the SQUARE of the input (and use
the previous sample when a new one jumps up, which softens how brief
transients are caught), so it bites progressively harder as level rises.
Release speeds up and slows down with the signal. Automatic make-up gain
grows as the threshold drops, so it gets louder as it compresses.

Parameters:

- thresh_db  (Intensty)  -30 .. 0 dBFS, default 0
  Input peak level where the gain cells start to clamp. 0 dBFS = nearly
  untouched (the original's default, knob A 0). Original knob A: the
  detector compares x^2 with 1.001 - (1 - (1-A)^3), so A 0.5 = -9.6 dBFS,
  A 0.7 = -15.3 dBFS, A 1 = -30 dBFS. Make-up gain rises with it
  (about +2.5 dB on a tuba take at -12 dBFS) — set level with output_db.

- speed_pct  (Speed)  0 .. 100 %, default 50
  Release speed. Not calibrated in ms because the release is level
  dependent and not exponential; measured recovery to 63 % after a loud
  burst, at 48 kHz: 0 % ~1.4 s, 30 % ~0.5 s, 50 % ~125 ms, 70 % ~20 ms,
  90 % and up almost instant (pumping, distortion-like). Original knob B
  = pct/100. As in the original, release gets faster at higher sample
  rates.

- output_db  (Output)  -24 .. +6 dB, default 0
  Output level on top of the automatic make-up gain. The original knob C
  was linear 0..1; +6 dB is an extension.

- mix_pct  (Dry/Wet)  0 .. 100 %, default 100
  Linear blend with the dry signal.

Port notes: DSP matches the original double-precision path (differential
test vs. the airwindows C++, max diff below -135 dB). A random generator
that was advanced every sample but never read has been removed (no change
to the output; about 79% fewer ns/sample on a translated test harness).
The original's 1e-16 "residue" noise is omitted.
