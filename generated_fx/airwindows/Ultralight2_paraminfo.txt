Ultralight2 — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/ultralight2/

What it is: about the cheapest reverb that still sounds like one — a 4x4
Householder feedback matrix with optional highpass/lowpass on its paths,
fed by a prime-numbered predelay with a small allpass chain beside it,
then a FastDistance-style treble loss after the dry/wet. Written as a
low-CPU game-engine reverb; no early reflections. Internally runs at a
48 kHz-equivalent rate (in float32, like the original).

Parameters:

- damping_step  (Damping)  0 .. 9 (steps), default 6
  0 = reverb off (only predelay, allpasses and dry/wet remain: a blurry
  slapback). 1 = longest sustain ... 9 = shortest. Same numbers the
  original displays (knob A, int(A*9.99)).

- unsolid  (UnSolid)  0 .. 4 (steps), default 3
  How many of the four feedback paths get a highpass: more = brighter
  decay, less bass through the walls.

- unreflect  (UnReflc)  0 .. 4 (steps), default 3
  How many paths get a lowpass, counted from the other end of the
  matrix: 2 + 2 or 1 + 3 filter every path once, 4 + 4 filters every path
  both ways. Same numbers the original displays (int(knob*4.99)).

- predelay_ms  (Predlay)  0 .. 165 ms, default 81.4 ms
  Predelay; the allpass taps beside it follow (nested square roots of
  its prime index). Below ~0.1 ms the predelay and allpasses are off.
  The original knob D chose prime number D*998 from a table, in samples
  at 48 kHz (7919 samples = 165 ms); this port finds the prime for the
  time you ask for.

- mix_pct  (Dry/Wet)  0 .. 100 %, default 50
  Linear blend of reverb and dry signal.

- distance_pct  (Distnce)  0 .. 100 %, default 0
  FastDistance high-frequency loss applied after the dry/wet, so dry,
  predelay and reverb all sound further away together. Quadratic inside
  (up to 53 filter steps at 100 %).

Port notes: DSP matches the original (differential test vs. the airwindows
C++, max diff below -140 dB; float32 internals as in the source). The
random generator for the denormal guard runs on native integer operations
(bit-identical), about 40% fewer ns/sample on a translated test harness.
