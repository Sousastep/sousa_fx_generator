ButterComp2 — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/buttercomp2/

What it is: a very gentle "glue" compressor with no threshold, ratio or
attack controls. Each half of the waveform (positive / negative) has its own
gain cell, and two interleaved sets of those run on alternate samples, so
four compressors blend in parallel. It evens out the bulk of the waveform,
balances it between positive and negative, and soaks up treble detail in a
characteristic way; the release slows slightly while the output is hot.
Level-dependent: it works against full scale, so a quiet input barely
compresses — drive it.

Parameters:

- compress_db  (Compress)  0 .. 14 dB, default 0
  Input drive, which also sets how hard the gain cells work. Part of the
  drive is made up again after compression (net gain about +1/3 of the
  drive before compression bites). 0 = effectively bypassed.
  Original knob A = compress_db / 14.

- output_db  (Output)  -24 .. +6 dB, default 0
  Output trim. Original knob B was a linear gain of 2*B (0.5 = unity,
  1 = +6 dB). Because it comes before the dry/wet mix and the release
  modifier listens to the output, it slightly changes the release too.

- mix_pct  (Dry/Wet)  0 .. 100 %, default 100
  Linear blend of compressed and dry signal.

Port notes: DSP matches the original double-precision path (differential
test vs. the airwindows C++, max diff below -145 dB). Optimized: the
per-sample pow(x,2) became x*x, each polarity's gain target is computed
only when used, the sample-rate scaling is done once per block and an unused
noise generator was removed (output differs from the literal port by less
than -310 dB; about 40% fewer ns/sample on a translated test harness).
The original's 1e-16 "residue" noise is omitted.
