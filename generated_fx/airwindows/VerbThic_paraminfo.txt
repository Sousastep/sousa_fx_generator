VerbThic — Airwindows (Chris Johnson), MIT
Page: https://www.airwindows.com/verbthic/

What it is: VerbTiny's sibling with the opposite job. Same structure (a
genetically evolved 4x4 Householder reverb plus a dual-mono copy, with
Bezier undersampling and filtering), but its matrix has unusually LOW peak
energy relative to RMS, so instead of sounding far away it sits at the
same depth as the source and thickens it, like a fog. Its internal soft
saturation is an extreme variant of the TapeHack curve. Use it for body
rather than space.

Parameters:

- regen_pct  (Replace)  0 .. 100 %, default 75
  Galactic-style "replace": more regeneration in the 4x4 tank and, at the
  same time, less new input going in, so the tail grows longer and the
  reverb keeps more of its own sound. At 100 % no new input enters at
  all (only what is already circulating keeps going; from silence it
  stays silent). Original knob A: regen = 1 - (1-A)^2 (A 0.5 = 75 %).

- derez_khz  (Derez)  0.2 .. 24 kHz, default 24
  The rate the reverb tank runs at (Bezier undersampling, smoothly
  interpolated back to the host rate). 24 kHz is the cleanest setting the
  original reaches at 48 kHz (it always runs at least at half rate);
  lower = duller, grainier, "early digital reverb". Original knob B: a
  cycle of int(overallscale/B^2)+1 samples; this port picks the cycle
  nearest the rate you ask for.

- filter_khz  (Filter)  0.2 .. 24 kHz, default 24
  A second Bezier undersampler on the reverb output, used as a smooth
  lowpass: treble rolls off progressively from around half this rate.
  Same law as derez (original knob C).

- wider_pct  (Wider)  0 .. 100 %, default 0
  0 = the normal (fairly narrow) stereo reverb; toward 50 % a dual-mono
  copy of the reverb fades in (each side feeds only itself: very wide);
  above 50 % the normal reverb returns with one channel phase-flipped, so
  everything becomes side energy (hyper-wide). Settings between the
  landmarks use both reverbs and sound richest. Original knob D = pct/100.

- mix_pct  (Dry/Wet)  0 .. 100 %, default 100
  Linear blend with the dry signal.

Port notes: fixed a real port bug — `bezFraction/(bezFraction+1.0)` (and
the same for the filter) compiled to an integer division (0), which broke
the Bezier interpolation and put the old port up to -34 dB away from the
original (see docs/rnbo_codebox/example28.md). Now bit-identical to the
airwindows C++ in a differential test. The random generator for the
denormal guard runs on native integer operations (bit-identical), about
35% fewer ns/sample on a translated test harness.
