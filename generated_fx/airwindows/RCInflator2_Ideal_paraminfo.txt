RCInflator2 (Ideal Edition) — lewloiwc, v1.0 (JSFX for REAPER)
Source: repos/JSFX/Distortion/RCInflator2_Ideal.jsfx (ReaTeam JSFX)
Inspired by Sonnox Oxford Inflator and RCInflator (Oxford Edition) by
RCJacH with additions by sai'ke and chmaha. Not an airwindows plugin; it
just lives in this folder.

What it is: an Inflator-style loudness enhancer. A polynomial waveshaper
(shape set by Curve) is blended with the dry signal by Effect; it lifts
low-level detail and rounds peaks, so things feel louder and denser
without obvious clipping. The "Ideal" edition drops the quirks of the
Sonnox original. Optional 3-band split shapes lows, mids and highs
separately.

Parameters (JSFX slider units and defaults):

- input_db  (Input)  -6 .. +12 dB, default 0
  Gain before the shaper. Hotter = more of the waveform rides the curve.

- effect  (Effect)  0 .. 100 %, default 0
  Blend between dry (0) and fully shaped (100). At 0 the shaper is out
  of the path, but the input gain and input clamp still apply.

- curve  (Curve)  -50 .. +50, default 0
  Shape of the transfer curve (every curve still maps full scale to full
  scale). 0 is the classic Inflator curve (low levels lifted 1.5x / +3.5
  dB at full effect); +50 lifts low levels 2x (+6 dB, densest); -50 leaves
  low levels nearly linear and bends only near the top (gentlest).

- clip  (Clip 0 dB)  Off / On, default On
  On: the input is clamped to +/-1 (0 dBFS) before the shaper.
  Off: clamped to +/-2 (+6 dBFS), and the region between 1 and 2 is
  folded back by the curve (2y - y^2), which is softer but lets the
  output exceed 0 dBFS.

- band_split  (Band Split)  Off / On, default Off
  On: splits at 240 Hz and 2400 Hz (fixed) and shapes each band on its
  own, then sums. The low band no longer modulates the highs, at the cost
  of a little glue.

- effect_in  (Effect In)  Off / On, default On
  Off removes only the shaper; input gain, input clamp and output gain
  stay active (as in the JSFX), so it is a curve A/B, not a bypass.

- output_db  (Output)  -12 .. 0 dB, default 0
  Output attenuation (the JSFX has no output boost).

Port notes: line-by-line equivalent to the JSFX (reviewed against the
source; the JSFX itself cannot be run in the differential harness).
Parameters are the JSFX sliders unchanged — they were already in
musical units.
