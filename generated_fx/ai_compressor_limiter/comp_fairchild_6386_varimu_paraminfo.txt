EFFECT: comp_fairchild_6386_varimu
SOURCE: Raffensperger (DAFx-2012, "Toward a Wave Digital Filter Model of the
        Fairchild 670 Limiter", Sections 2, 5, 6; Eqs. 1, 10-14; Fig. 8; Table 3)
TYPE:   Stereo Variable-Mu 6386 Remote-Cutoff Triode Feedback Limiter with
        3-Capacitor Program-Dependent Memory & Lateral-Vertical (M/S) Matrix
================================================================================

OVERVIEW
--------
Models the 1950s Fairchild 670 stereo variable-mu vacuum-tube feedback limiter.
Its sidechain monitors the output signal through a Class-B crossover stage with
interacting AC and DC threshold controls (Eq. 10), rectified into a three-capacitor
RC network (CT fast, CU medium, CV slow memory, Fig. 8 & Table 3) that elongates
release time after sustained heavy peaks. The signal path models a balanced
push-pull pair of GE 6386 remote-cutoff triodes whose odd-order harmonic
saturation increases proportionally with gain reduction (Sec. 6, Fig. 13).

PARAMETERS (9 total)
--------------------
1. input_gain_db   [-24.0 .. +36.0 dB, default: 0.0]
   Input trim, a plain gain stage ahead of the input transformer. Raising it
   feeds more level into the existing limiter (so it limits harder, as on real
   hardware); it does not alter any other setting.

2. drive_db        [0.0 .. 24.0 dB, default: 8.0]
   Input step attenuator / transformer drive into the 6386 variable-mu stage.

3. ac_thresh       [0.0 .. 1.0, default: 0.55]
   Front-panel AC Threshold (phi_AC): controls sidechain sensitivity and amount
   of feedback limiting.

4. dc_knee         [0.0 .. 1.0, default: 0.25]
   Under-chassis DC Threshold (phi_DC, Eq. 10): biases the Class-B sidechain
   crossover stage, continuously morphing from soft vari-mu compression to hard
   brickwall limiting.

5. tc_mode         [1.0 .. 6.0, default: 5.0]
   Six-way Fairchild Time-Constant selector (Table 3); continuous, snaps to
   the nearest position:
   - 1..4: Single-RC release (100 ms, 300 ms, 880 ms, 1.76 s).
   - 5: Dual-RC program-dependent release (CT + CU).
   - 6: Triple-RC dual-memory auto-release (CT + CU + CV) for fast transient
        recovery and slow sustained leveling.

6. tube_harmonics  [0.0 .. 1.0, default: 0.5]
   Gain-reduction-dependent push-pull 6386 3rd-harmonic saturation depth
   (Raffensperger Sec. 6, Fig. 13).

7. lat_vert_mode   [0.0 .. 1.0, default: 0.35]
   Crossfade between Left/Right independent feedback limiting (0.0) and
   Lateral/Vertical (Mid-Side) limiting (1.0), as on the 670's mode switch.
   In between, both limiter pairs run and their outputs are blended, so the
   image stays centred at every setting. In Lateral/Vertical mode a centred
   (mono) source lands entirely in the Lateral channel, about 3 dB hotter, so
   it limits a little harder than in Left/Right mode; a hit in the middle
   ducks the centre while the sides (room, chorus width) stay up.
   CPU: 0.0 or 1.0 runs one limiter pair; anything in between runs two.

8. mix             [0.0 .. 1.0, default: 1.0]
   Dry/wet parallel NY-compression blend.

9. output_gain_db  [-24.0 .. +36.0 dB, default: 0.0]
   Output trim, a plain gain stage after the feedback tap and the dry/wet
   blend, so it makes the effect up or down in level without feeding back into
   the sidechain.

INLETS / OUTLETS
----------------
- in1 / in2: stereo audio. If in2 stays silent for 250 ms, in1 is used for both
  sides (so a mono patch into in1 works).
- in3 / in4: not used.
- out1 / out2: stereo.

NOTES
-----
- Params 1 and 9 (input/output gain) were added on request on top of the
  8-parameter guideline; they are plain trims and do not change the model.
- Earlier versions blended the L/R and M/S matrices directly, which left the
  right side quieter on mono input at the default 0.35 (several dB, more under
  heavy limiting); the two-pair crossfade replaces that.
