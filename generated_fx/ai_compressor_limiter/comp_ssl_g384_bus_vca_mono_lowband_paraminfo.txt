EFFECT: comp_ssl_g384_bus_vca_mono_lowband
SOURCE: Thompson & Heilemann (DAFx-2026, "Evaluating Dynamic Range Compressor
        Models Using Control-Voltage Measurements: An Approach and Dataset",
        Sections 3 & 4.1)
TYPE:   Mono SSL Logic FX G384 / 4000 G-Series Bus VCA Compressor, Low-Band
        Variant with RMS-Style Detector
================================================================================

OVERVIEW
--------
comp_ssl_g384_bus_vca_mono re-tuned for the low band of a crossover (e.g. the
tuba below a 100 Hz Linkwitz-Riley split). Same ratio-dependent knee, AUTO
release circuit, automatic makeup and THAT 202 VCA stage, with these changes:

- The detector is RMS-style (square -> one-pole smoothing -> square root,
  scaled by sqrt(2) so a sine reads its peak amplitude and the threshold sits
  where it does on the peak version). The raw peak detector of the other
  versions makes the gain wobble at twice the note frequency on low notes;
  this one barely does (about +/-0.2 dB at 41 Hz with the defaults).
- New detector_ms control for that smoothing.
- Sidechain HPF default 20 Hz, so the detector actually hears the low band.
- AUTO release off and a long 0.75 s manual release by default.
- Attack range widened to 100 ms, default 30 ms.
- VCA harmonics off by default.

INLETS / OUTLETS
----------------
- in1: mono audio. in2, in3 and in4 are not used.
- out1 / out2: the same processed mono signal, so it drops into a stereo chain.

PARAMETERS (11 total)
---------------------
(Params 1 and 11, input/output gain, were added on request on top of the
8-parameter guideline; they are plain trims and do not change the model.)

1. input_gain_db   [-24.0 .. +36.0 dB, default: 0.0]
   Input trim ahead of the sidechain tap. More input = more compression; the
   dry signal (mix) is trimmed too.

2. thresh_db       [-36.0 .. 0.0 dB, default: -18.0]
   Compression threshold, with automatic makeup (about half the reduction a
   0 dBFS peak would get).

3. ratio_mode      [2.0 .. 10.0, default: 4.0]
   Compression ratio 2:1 .. 10:1; the knee narrows from 14 dB at 2:1 to 4 dB
   at 10:1.

4. attack_ms       [0.1 .. 100.0 ms, default: 30.0]
   Gain attack time constant. Slow attacks let the front of each tongued note
   through before the gain clamps.

5. release_s       [0.05 .. 1.5 s, default: 0.75]
   Manual single-pole release time constant (used fully when auto_release
   is 0).

6. auto_release    [0.0 .. 1.0, default: 0.0]
   Blends in the SSL two-pole AUTO release (75 ms fast pole plus a 1.25 s slow
   program pole). At 1 release_s is ignored.

7. sc_hpf_hz       [20.0 .. 350.0 Hz, default: 20.0]
   Sidechain high-pass cutoff. Keep it low on a low band: raising it above the
   crossover frequency leaves the detector almost nothing to hear.

8. detector_ms     [1.0 .. 100.0 ms, default: 30.0]
   RMS detector smoothing time. Longer = smoother gain on low notes but a
   slower response (it adds to attack_ms). Below ~10 ms the 2x-frequency
   wobble starts to come back on the lowest notes.

9. vca_harmonics   [0.0 .. 1.0, default: 0.0]
   THAT 202 audio VCA odd/even harmonic saturation, rising with gain
   reduction.

10. mix            [0.0 .. 1.0, default: 1.0]
   Dry/wet parallel compression blend.

11. output_gain_db [-24.0 .. +36.0 dB, default: 0.0]
   Output trim after the dry/wet blend; does not feed the detector.
