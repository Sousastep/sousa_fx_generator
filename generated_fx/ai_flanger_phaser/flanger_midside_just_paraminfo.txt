================================================================================
flanger_midside_just — Parameter Information
================================================================================

WHAT IT IS
A flanger that treats the centre and the sides of the stereo image as two
separate combs. The mid comb stays tuned to the played note; the side comb is
tuned a 5-limit interval above it. Because both combs come from one delay and
one ratio, that interval is exact at every point of the sweep — the width pumps
and breathes while the mono core stays locked, which is what keeps a sub-heavy
deep-dubstep bass from wandering when you flange it.

The side comb is fed by the input's own L−R signal plus a copy of the mid
high-passed at 150 Hz, so a mono (dual-mono) tuba still gets a side comb and
real width; everything below ~150 Hz stays in the centre. On a mono input the
output can peak about +3.5 dB above the input at full side_width = 1.

Source: Das, DAFx-24 paper 92 §3 (width from the difference channel);
Esqueda/Välimäki/Parker, DAFx-15 §3 Fig. 6; 5-limit ratios per Tong & Tojo,
SMC-19 §2.

100% wet. No dry/wet control, no limiter.

PARAMETERS (7)

1. mid_ms — 0.5…12 ms, default 3 ms
   Mid comb spacing. The delay snaps to the note's period divided by a whole
   number N (the nearest to the knob), so the comb's peaks land on every N-th
   harmonic of the tuba and its notches sit halfway between them — the comb is
   on the tuba's own grid instead of an arbitrary delay. On a low A (55 Hz):
   0.5 ms ≈ peaks every 36th harmonic (~2 kHz apart: few broad notches, jet-
   like), 12 ms ≈ every 2nd harmonic (dense, metallic comb). The sweep (depth)
   moves it off the grid and back.

2. side_ratio — 1/1, 6/5, 5/4, 4/3, 3/2, 2/1; default 3/2
   Interval of the side comb above the mid comb. 1/1 = mono-width (no widening,
   just a second comb), 3/2 = a fifth — the widest and most natural, 2/1 = an
   octave, which puts the side notches on the mid notches' peaks and cancels the
   width oddly. All are ratios of small integers, never cent values.

3. rate_hz — 0.02…2 Hz, default 0.11 Hz
   Sweep speed.

4. depth — 0…1, default 0.7
   Sweep depth, in octaves of comb spacing (±0.5 octave at 1). Both combs scale
   together, so the mid/side interval never drifts off the just ratio.

5. feedback — -0.85…+0.85, default +0.35
   Recirculation of the delayed taps on both combs (the dry is not fed back).
   Positive makes the comb peaks ring; negative shifts the ringing between them
   for a hollower sound. Applied to mid and side equally, so the width
   relationship is untouched. Near ±0.85 the peaks are up to ~+12 dB.

6. side_width — 0…2, default 1.0
   1.0 = unity side gain (normal width), 0 = mono (mid only), 2 = doubled side
   (very wide, check mono compatibility).

7. out_gain_db — -24…+12 dB, default 0 dB
   Final trim.

INLETS / OUTLETS
- in1 / in2: stereo audio.
- in3: f0 in Hz. 0 or out of range = unknown: the last valid value is held.
  Cold start 55 Hz (A1), so the comb is tuned with nothing patched.
- in4: 0..1 one-bar phasor (not Hz). While it moves the sweep runs exactly one
  full cycle per bar and rate_hz is ignored; held constant or unconnected the
  effect free-runs at rate_hz. A stepped (non-phasor) signal here will jump
  the sweep phase.
- out1 / out2: stereo, wet only.

NOTES
- Because the comb spacing snaps to harmonics of f0, playing a different note
  re-tunes the combs; the delay glides over ~20 ms rather than jumping.
- Mid and side each have their own feedback path, so the width does not collapse
  when the mid is resonating.
