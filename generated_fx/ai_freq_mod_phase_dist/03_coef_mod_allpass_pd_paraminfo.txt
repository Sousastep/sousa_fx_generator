================================================================================
03_coef_mod_allpass_pd — Parameter Information
================================================================================

OVERVIEW
Implements the ICASSP 2009 paper by Timoney, Lazzarini, Pekonen, and Välimäki ("Spectrally Rich Phase Distortion Sound Synthesis Using an Allpass Filter"). Modulates the coefficient a(t) in [0, 1] of a first-order allpass filter at the tuba's fundamental frequency using a piecewise sawtooth phase-deviation function smoothed with a hyperbolic tangent mapping (Eq. 6–9). Unlike wavetable Phase Distortion, this applies true phase distortion directly to the full arbitrary brass signal with a richer high-frequency roll-off and no missing harmonics.

INLETS & OUTLETS
- in1 / in2: Stereo Audio Input (Left / Right)
- in3: Tracked Fundamental Pitch in Hz (from fluid.pitch~; falls back to internal zero-crossing tracker if <= 0)
- out1 / out2: Stereo Allpass Phase-Distorted Output

PARAMETERS (4)

1. pd_depth
   - Range: 0.0 to 1.0 (0% to 100% Phase Deviation Index)
   - Taper: Power curve (x^1.3) for fine control in the subtle-to-medium brass brightening zone and rapid saturation near 1.0 where coefficient modulation approaches 0.95.
   - Function: Scales the instantaneous phase deviation phi_mod(t) and resulting frequency excursion imparted to each cycle of the tuba.

2. knee_p
   - Range: 0.05 to 0.95 (Inflection Point P of the Cycle)
   - Taper: Linear duty fraction (0.25 matches the paper's classic sawtooth PD inflection point; extreme values near 0.05 or 0.95 create sharp, bitey brass edges).
   - Function: Sets the fraction P of the fundamental period during which the phase modulation rises before falling for the remainder (1 - P) of the cycle.

3. smooth_beta
   - Range: 0.0 to 1.0 (maps to beta in [1.0, 1.85] in Eq. 9: m'(t) = tanh(alpha*m(t) - beta))
   - Taper: Linear mapping to the paper's tanh dip-smoothing constants (0.5 corresponds to the paper's optimal alpha = 1.40, beta = 1.45).
   - Function: Controls the smoothing of the sharp dips at the phase-inflection boundary. Low values retain a raw, glitchy digital bite; higher values yield a smooth, analog-sawtooth spectral roll-off.

4. mix
   - Range: 0.0 to 1.0 (0% Dry to 100% Wet)
   - Taper: Linear crossfade (summing dry and wet creates additional pitch-locked notch animation).
   - Function: Blends between the dry stereo input and the coefficient-modulated allpass output.
