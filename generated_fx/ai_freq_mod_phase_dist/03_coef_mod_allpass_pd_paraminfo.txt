================================================================================
03_coef_mod_allpass_pd — Parameter Information
================================================================================

OVERVIEW
Implements the ICASSP 2009 paper by Timoney, Lazzarini, Pekonen, and Välimäki ("Spectrally Rich Phase Distortion Sound Synthesis Using an Allpass Filter"). Modulates the coefficient a(t) in [0, 1] of a first-order allpass filter at the tuba's fundamental frequency using a piecewise (skewed-triangle) phase-deviation function: the deviation d(t) is converted to the coefficient that gives exactly that phase lag at f0 (Eq. 6, tan form), split over two cascaded allpass stages. Low notes need a coefficient very close to 1 (up to 0.9995). Unlike wavetable Phase Distortion, this applies true phase distortion directly to the full arbitrary brass signal with a richer high-frequency roll-off and no missing harmonics.

INLETS & OUTLETS
- in1 / in2: Stereo Audio Input (Left / Right)
- in3: Tracked Fundamental Pitch in Hz (from fluid.pitch~; falls back to internal zero-crossing tracker if <= 0)
- out1 / out2: Stereo Allpass Phase-Distorted Output (the Right channel's modulation runs up to 0.12 cycle ahead for width)
- Level: unity within about 1 dB (allpass). Measured on a 58 Hz sine (offline render of the real RNBO code): 2nd harmonic -24 / -8 / -5 dB relative to the fundamental at pd_depth 0.5 / 0.75 / 1.0; similar at 37 and 233 Hz.

PARAMETERS (4)

1. pd_depth
   - Range: 0.0 to 1.0 (0% to 100% Phase Deviation Index)
   - Taper: Power curve (x^1.3); full depth is a peak phase deviation of about 0.98 * pi per cycle.
   - Function: Scales the instantaneous phase deviation phi_mod(t) and resulting frequency excursion imparted to each cycle of the tuba.

2. knee_p
   - Range: 0.05 to 0.95 (Inflection Point P of the Cycle)
   - Taper: Linear duty fraction (0.25 matches the paper's classic sawtooth PD inflection point; extreme values near 0.05 or 0.95 create sharp, bitey brass edges).
   - Function: Sets the fraction P of the fundamental period during which the phase modulation rises before falling for the remainder (1 - P) of the cycle.

3. smooth_beta
   - Range: 0.0 to 1.0 (smoothing corner 32 x f0 at 0, 5.7 x f0 at the 0.5 default, 1 x f0 at 1.0)
   - Taper: Exponential in the corner frequency (one octave per 0.2), always relative to the tracked pitch.
   - Function: One-pole smoothing of the phase-deviation curve at its inflection points. Low values retain a raw, bitey edge; higher values yield a smooth, analog-sawtooth spectral roll-off (about 7 dB less 4th harmonic from 0 to 1). The name is kept from the earlier Eq. (9) tanh version, which pinned the coefficient and made the effect nearly inaudible.

4. mix
   - Range: 0.0 to 1.0 (0% Dry to 100% Wet)
   - Taper: Linear crossfade (summing dry and wet creates additional pitch-locked notch animation).
   - Function: Blends between the dry stereo input and the coefficient-modulated allpass output.
