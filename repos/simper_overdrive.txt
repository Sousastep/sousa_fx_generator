v2: warm-started, bracketed Newton + numeric clamps + convergence check
============================================================================
The circuit and the solved-for fixed point are unchanged from the original;
this version replaces the fixed 20-iteration loop with a warm-started,
bracketed Newton solve, and makes the numerics safe for float32 (the
original could NaN on inputs over ~2.3 V -- see NUMERICS).

CIRCUIT MODEL
-------------
Non-inverting op-amp stage: R1 from the inverting input to ground, and a
feedback network (R2 in parallel with antiparallel diodes D1/D2) from the
output back to the inverting input. The op-amp forces the inverting input
to Vin, and KCL at that node determines Vout. Writing vd = Vout - Vin (the
diode-stack voltage), the residual the original solver iterates on is:

    f(vd) = vd*gr1 - Vin*gr2 - (id1 - id2) = 0
    vd1 = -vd   (D1: anode at node, cathode at Vout)
    vd2 = +vd   (D2: cathode at node, anode at Vout)

which is exactly the fixed point of the original update formula
    vsol = ( Vin*(gr1 + gr2 + gd1 + gd2) + id1eq - id2eq ) / (gr1 + gd1 + gd2)
i.e. vsol*gr1 = Vin*(gr1 + gr2) + id1 - id2. This version solves that same
equation, but for vd directly instead of iterating on Vout, for the
numerical reasons below.

NUMERICS (warm-started, bracketed Newton on the diode voltage)
--------------------------------------------------------------
* Solve for vd = Vout - Vin instead of Vout. vd is physically bounded to
  about +-0.8 V for any current the resistors can supply (vd = Vt*ln(id/Is)),
  so the seed, the iterate box and the solution bracket are all +-VD_CLAMP.
* Bracketed Newton: f(vd) is strictly monotone increasing (df/dvd =
  gr1 + gd1 + gd2 > 0), so the root is bracketed by f(-VD_CLAMP) < 0 <
  f(VD_CLAMP). Each iteration shrinks the bracket with the current point's
  sign, then takes the Newton step only when it is safe (aggressive: at
  least half a bracket-width away, or residual already small);  otherwise it
  takes the bracket midpoint. Midpoints halve the bracket and accepted
  Newton steps only occur where they are exact (linear region) or already
  near the root, so in practice the solve stays within ~15 iterations no
  matter how bad the seed. This is what makes it robust where a bare Newton
  loop is not: a raw Newton step from a cold/far seed can jump to ~2*Vin
  (deep into the exponential, where Newton then crawls at ~Vt per iteration
  and never finishes in budget), and at high gain the diode voltage swings
  as gain*Vin through the linear region, which sign-flips the seed.
* Warm start: the previous sample's diode voltage is kept in a History
  variable and used as the next sample's seed. vd changes far more slowly
  than the signal itself (it is ~0.7 V whether the input is quiet or loud,
  and only tracks Vin logarithmically), so the seed is typically within a
  few millivolts of the new solution and the loop finishes in 1-3
  iterations instead of the fixed 20 the original burned on every sample.
  Because the nonlinearity runs at 4x the base rate, the four branch calls
  share this History in time order, giving exactly time-adjacent seeds.
* VD_CLAMP = 1.2 V is comfortably above the true solution (reaching it
  needs ~kA of diode current) and keeps every exp() argument below
  EXP_CLAMP*VT (~2.21 V), so the exponential is never clamped while Newton
  is solving -- the clamp box can never create the spurious fixed points
  described in diode_clip.txt.
* The exp() argument is additionally clamped to +-EXP_CLAMP as a last line
  of defense: float32 exp() overflows to inf at |arg| ~= 88, and inf/inf
  gives NaN, which would permanently poison the History state (a NaN in a
  gen history never recovers). With the diode-voltage clamp above this is
  never active -- it is belt-and-braces. (The original had no clamps at all:
  on the first iteration v_out = 0 so vd1 = v_in, and any |v_in| > ~2.3 V
  made exp() overflow and the whole sample come out NaN.)
* If the warm-started solve fails to converge, a cold restart from vd = 0
  is attempted (also clamped to +-VD_CLAMP).
* gain is clamped to [0.01, 100] so gr1 = 1/(gain*10000) can never become
  infinite (gain = 0 would divide by zero).

PARAMETER PLACEMENT
-------------------
genexpr requires all function definitions to precede every statement:
  circuit parameters (IS, VT)        -> declared in DiodeDistortion, passed
                                        into diodeSolve as arguments
  conductances (gr1, gr2)            -> computed in DiodeDistortion from the
                                        gain, passed into diodeSolve
  solver parameters (MAX_ITER, TOL,
                     F_TOL, VD_CLAMP, EXP_CLAMP) -> declared inside diodeSolve
  derived value (invVt)              -> computed inside diodeSolve

PATCH I/O
---------
  in1  audio input
  in2  gain (clipped to [0.01, 100]) -> scales R1; sets the clip knee
  out1 processed audio, DC-blocked

The audio is oversampled 4x with polyphase-IIR halfband filters so the
clipping harmonics alias less, then downsampled and DC-blocked.
============================================================================
*/

require("halfband_ppiir.genexpr");
// ----------------------------------------------------------------------------
// One solve of the diode network for a fixed v_in, starting from a seed for
// the diode voltage vd = Vout - Vin (usually the previous sample's converged
// vd, passed in as seed_offset). Circuit values (is, vt) and conductances
// (gr1, gr2) are owned by DiodeDistortion and passed in; solver parameters
// are declared here. Returns the solution vsol and whether it converged.
// ----------------------------------------------------------------------------

diodeSolve(v_in, seed_offset, gr1, gr2, is, vt)
{
    // ---- solver parameters ----
    MAX_ITER = 20;
    VD_CLAMP = 1.2;
    EXP_CLAMP = 85.0;

    invVt = 1.0 / vt;

    vd = clip(seed_offset, -VD_CLAMP, VD_CLAMP);
    lo = -VD_CLAMP;
    hi = VD_CLAMP;

    ed1 = exp(clip(-vd * invVt, -EXP_CLAMP, EXP_CLAMP));
    id1 = is * ed1 - is;
    gd1 = is * ed1 * invVt;

    ed2 = exp(clip(vd * invVt, -EXP_CLAMP, EXP_CLAMP));
    id2 = is * ed2 - is;
    gd2 = is * ed2 * invVt;

    f = vd * gr1 - v_in * gr2 - (id1 - id2);

    for (i = 0; i < MAX_ITER; i += 1) {

        if (f > 0) { hi = vd; } else { lo = vd; }

        vd_new = vd;

        vd_newton = vd - f / (gr1 + gd1 + gd2);
        take_newton = 0;
        if (vd_newton > lo && vd_newton < hi) {
            if (abs(f) < 0.001) { take_newton = 1; }
            else if (abs(vd_newton - vd) >= (hi - lo) * 0.5) { take_newton = 1; }
        }
        if (take_newton == 1) {
            vd_new = vd_newton;
        } else {
            vd_new = (lo + hi) * 0.5;
        }

        ed1 = exp(clip(-vd_new * invVt, -EXP_CLAMP, EXP_CLAMP));
        id1 = is * ed1 - is;
        gd1 = is * ed1 * invVt;

        ed2 = exp(clip(vd_new * invVt, -EXP_CLAMP, EXP_CLAMP));
        id2 = is * ed2 - is;
        gd2 = is * ed2 * invVt;

        vd = vd_new;
        f = vd * gr1 - v_in * gr2 - (id1 - id2);
    }

    return v_in + vd, 1;
}

// ----------------------------------------------------------------------------
// Per-sample diode overdrive. v_out is a History variable holding the
// previous sample's converged solution; vd_prev holds the previous sample's
// diode voltage, used to warm-start the next solve. DiodeDistortion is
// called on up0..up3 in time order, so its shared History state warm-starts
// each branch from the previous branch's solution -- exactly the right
// time-adjacent seed.
// ----------------------------------------------------------------------------
DiodeDistortion (v_in, gain) {

    History v_out(0);
    History vd_prev(0);

    // ---- circuit parameters (owned by the circuit stage) ----
    is = 1E-15;              // diode saturation current [A]
    vt = 26E-3;              // thermal voltage [V] (kT/q at ~25 C)
    gr1 = 1.0/(gain * 10000);  // input-side conductance [S], gain-scaled
    gr2 = 1.0/10000;           // feedback conductance [S]

    // warm-started solve (diodeSolve clamps the seed internally)
    v_out, converged = diodeSolve(v_in, vd_prev, gr1, gr2, is, vt);

    // fallback: cold restart from vd = 0 if the warm start misbehaved.
    // (Best-effort: v_out is still clamped and finite.)
    if (!converged) {
        v_out, converged = diodeSolve(v_in, 0, gr1, gr2, is, vt);
    }

    vd_prev = v_out - v_in;   // remember this sample's diode voltage

    return v_out;
}

// ---- main signal path ----

gain = clip(in2, 0.01, 100);   // keep gr1 finite and the solve well-posed

up0, up1, up2, up3 = upsample4x_ppiir(in1);

up0 = DiodeDistortion(up0, gain);
up1 = DiodeDistortion(up1, gain);
up2 = DiodeDistortion(up2, gain);
up3 = DiodeDistortion(up3, gain);

out1 = dcblock(downsample4x_ppiir(up0, up1, up2, up3));
